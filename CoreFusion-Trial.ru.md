# CoreFusion: приглашение к публичному тестированию

> xray-ui больше не поддерживается и будет переведён в режим «только чтение». Основной проект теперь — CoreFusion. Приглашаем попробовать его в тестовой среде, сообщать о проблемах, писать руководства и записывать видео.

Другие языки: [中文](CoreFusion试用与建议.md) · [English](CoreFusion-Trial.en.md) · [فارسی](CoreFusion-Trial.fa.md)

## 1. Что будет с xray-ui

- Этот проект (xray-ui) **больше не поддерживается** и в ближайшее время станет **репозиторием только для чтения**.
- Уже развёрнутые экземпляры продолжат работать, но новых функций, исправлений совместимости и обновлений безопасности не будет.
- После архивации репозитория issues также будут закрыты. Если что-то нужно обсудить, используйте репозиторий CoreFusion.

CoreFusion: <https://github.com/qist/corefusion>

## 2. Что такое CoreFusion

Это отдельный продукт, а не «обновление» xray-ui:

| | xray-ui (этот проект) | CoreFusion |
|---|---|---|
| Назначение | Панель для одного сервера, управляет локальным Xray | Панель + Агент для нескольких узлов |
| Кому подходит | Один VPS, личное использование | Несколько узлов, раздача подписок |
| Ядро | Xray-core | Xray-core + sing-box |
| Для эксплуатации | — | Тарифы/заказы/портал, автосертификаты, квоты и ограничение скорости, WAF, аудит, мультиязычность |

Если у вас одна машина для себя — можно остаться на текущей панели. Если узлов несколько или нужно продавать подписки — попробуйте CoreFusion на тестовой машине.

## 3. Текущий этап

**Публичная бета.**

Что уже работает:

- Установка, мастер первоначальной настройки, вход в панель и обновление версии
- Несколько узлов: подключение Агента, переподключение, доставка конфигурации
- Ядра Xray и sing-box; распространённые протоколы и транспорты (VLESS + Reality, Hysteria2, TUIC, WS, gRPC, XHTTP и др.)
- Выдача подписок (Clash/Mihomo в обычном режиме и в режиме provider, sing-box, Xray, Base64)
- Шаблоны тарифов, привязка подписок, срок действия и лимиты трафика, клиентский портал
- Автоматическая выдача и продление сертификатов, рассылка на узлы
- Учёт трафика и ограничение скорости

Но для **масштабной эксплуатации он не готов**:

- Множество граничных случаев не проверено, проблемы ожидаемы
- Структуры данных и API могут меняться между версиями; обратная совместимость при обновлении не гарантируется
- Нет SLA, время восстановления не гарантируется
- **Не используйте его для реального бизнеса, платных услуг или продакшена**; сначала проверьте на тестовой машине, тестовых доменах и тестовых аккаунтах

## 4. Как попробовать

> Около 10 минут до первого запуска. Только тестовая машина или запасной VPS. Не перезаписывайте машину, на которой работает xray-ui; если нужно совместить — используйте отдельный каталог и порты.

```bash
curl -fsSL https://raw.githubusercontent.com/qist/corefusion/main/scripts/install.sh -o install.sh
sudo bash install.sh
```

После установки терминал выведет адрес мастера настройки и одноразовый токен (действует 2 часа). Откройте адрес, создайте администратора, задайте порт панели и войдите.

Основные параметры:

```bash
sudo bash install.sh --lang en                    # язык вывода установщика: zh|en|fa|ru
sudo bash install.sh --version v0.13.0-beta.96    # фиксированная версия
sudo bash install.sh --mirror https://ghproxy.net # ускоритель загрузки
```

Рекомендуемый порядок:

1. Мастер настройки: база данных (по умолчанию SQLite) → каталог данных → ключ шифрования → установка ядра → прокси (нет / Nginx / Caddy) → сайт и домены → сертификаты → сохранить и перезапустить
2. Добавить узел: «Управление узлами» → «Новый сервер»
3. Развернуть Агент: нажать Bootstrap и выполнить выведенную команду от root на целевом узле
4. Центр протоколов: сначала поднимите один входящий VLESS + Reality или Hysteria2
5. Подписки: создайте формат подписки, затем привяжите тарифы и подписки в «Управлении клиентами»
6. Клиент: импортируйте подписку в Clash Verge / Mihomo / sing-box и проверьте узлы и группы

## 5. Обратная связь: только issues, без PR

На этапе беты **Pull Request не принимаются**. Код меняется быстро, а проверка и слияние внешних PR стоят дороже, чем приносят пользы. Спасибо за понимание.

- Ошибки / сбои: создайте issue на <https://github.com/qist/corefusion/issues> по шаблону отчёта об ошибке
- Предложения / замечания по интерфейсу: тоже issue, с префиксом `[Feature]` в заголовке
- Для удобства сортировки укажите «из тестирования xray-ui»

Пожалуйста, приложите:

- Версию: `corefusion --version` на панели
- ОС и архитектуру (например, Debian 12 / amd64, контейнер или нет)
- Шаги воспроизведения (чем короче, тем лучше)
- Логи: панель `journalctl -u corefusion -n 200 --no-pager`; узел `journalctl -u corefusion-agent -n 200 --no-pager`

## 6. Языки и переводы

Интерфейс панели доступен на **16 языках**:

| Язык | Код | Язык | Код |
|---|---|---|---|
| Китайский (упрощённый) | zh-CN | Китайский (традиционный) | zh-TW |
| Английский | en | Японский | ja |
| Корейский | ko | Немецкий | de |
| Французский | fr | Испанский | es |
| Португальский | pt | Русский | ru |
| Арабский | ar | Персидский | fa |
| Индонезийский | id | Тайский | th |
| Турецкий | tr | Вьетнамский | vi |

Документация доступна на тех же языках: README проекта, руководство пользователя и документация API находятся в каталоге `docs/`. Вывод установщика поддерживает 4 языка (zh / en / fa / ru); язык интерфейса переключается после входа в панель.

Большая часть переводов сделана с помощью машинного перевода, поэтому **формулировки и терминология могут быть неточными**, особенно сетевые и прокси-термины. Если нашли ошибку, создайте issue и укажите:

- язык (например, ja / de / ru)
- страницу или ключ перевода
- предлагаемый вариант

Исправления от носителей языка обрабатываются в первую очередь.

## 7. Руководства и видео приветствуются

Проект молодой, и материалы, по которым «другой человек сможет повторить и получить результат», сейчас важнее любых функций.

- Текстовые руководства, пошаговые инструкции, видео, статьи в блогах и на каналах — всё приветствуется
- Не обязательно делать полноценный материал: один реальный сценарий (установка, Reality, Hysteria2, подписки, портал, сертификаты…) уже полезен
- Когда закончите, создайте issue в репозитории CoreFusion со ссылкой — материал можно будет добавить в документацию или README
- Укажите использованную версию (`corefusion --version`), чтобы более поздние изменения не вводили читателей в заблуждение
- Не публикуйте в руководствах реальные ссылки на подписки, токены, приватные ключи и пароли серверов

## 8. Известные ограничения

- Нет импорта конфигураций и аккаунтов из xray-ui в один клик; миграция означает настройку в новой среде
- Панель и Агент общаются по mTLS; после истечения сертификата узла требуется повторный Bootstrap (это ожидаемое поведение, а не сбой панели)
- Перед обновлением беты делайте резервную копию каталога `data/` (база, сертификаты, рабочая конфигурация)
- Функции подписок, оплаты и сертификатов сначала проверяйте на тестовых доменах и аккаунтах
